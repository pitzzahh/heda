**HEDA** is a tool for electrical engineers. It covers load scheduling, voltage drop analysis, and short circuit calculations.

---

## Features

- **Load Scheduling**  
  Plan and organize electrical loads.

- **Voltage Drop Analysis**  
  Analyze voltage drops across circuits.

- **Short Circuit Calculations**  
  Run short circuit calculations.
